# Sneh Srijan — Portfolio

A responsive, single-page portfolio for Sneh Srijan, focused on event operations and programme coordination.

## Preview locally

Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a public repository named `sneh-srijan-portfolio` in the GitHub account `snehsrijan`.
2. Upload the contents of this folder (the files themselves, not the enclosing folder) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. After GitHub Pages finishes publishing, the site should be available at:
   `https://snehsrijan.github.io/sneh-srijan-portfolio/`

## Personalisation before publishing

- Replace the abstract artwork in the hero with Sneh's approved portrait when it is provided. The current design intentionally uses a portrait placeholder, not a stock photo.
- Add a resume PDF in this folder and a download link if a public downloadable CV is wanted.
- Confirm the event descriptions and dates before making the site public.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — place the approved profile photo and other assets here
