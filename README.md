# Sneh Srijan — Portfolio Website

A responsive, premium editorial-style resume/portfolio website.

## Files
- `index.html` — page structure and resume content
- `styles.css` — typography, color palette, layout, cards and responsive styling
- `script.js` — small footer-year enhancement

## Styling choices
- **Fonts:** Playfair Display for editorial headings; DM Sans for readable body text.
- **Palette:** warm ivory, muted olive, soft gold and deep charcoal.
- **Layout:** sticky navigation, split hero, section bands, experience timeline, capability cards and contact section.
- **Responsive CSS:** desktop, tablet and mobile breakpoints.

## Preview locally
Open `index.html` in a browser. An internet connection is needed to load Google Fonts; system fallbacks are included.

## Publish with GitHub Pages
1. Upload all files to the root of `snehsrijan/sneh-srijan-portfolio`.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. The expected site address is `https://snehsrijan.github.io/sneh-srijan-portfolio/`.

## Before publishing
- Verify resume dates and role details.
- Add Sneh's approved profile photo if desired; the hero currently uses an abstract CSS illustration.
- Confirm the contact details and LinkedIn URL.
